# Corrections and additions

Open an issue or pull request describing the affected canonical pair `(r,s)`, with `r <= s`.

1. Link an externally accessible mathematical source and give the exact theorem, page, or table location. Include authors, publication status, DOI, and versioned arXiv identifier where available.
2. State the coefficient field and the convention for squares and bilinearity. Explain any transfer to C.
3. Justify lower and upper bounds separately. A construction described as optimal still needs an identifiable lower-bound authority.
4. If derived, list the input results, operation, output bound, and a short proof. Preserve source orientation. Restrictions and direct sums must identify all input dimensions.
5. Update the source registry, derivations, source-table inputs or builder as appropriate, then rebuild and run all README checks. Do not hand-edit generated Markdown.
6. Record conflicting claims and their resolution in `audits/CONFLICTS.md`. Leave unresolved claims out of the accepted frontier until adjudicated; document the gap.

Secondary sources are discovery aids. A preprint is eligible, with its status and exact version visible. Private correspondence, inaccessible internal results, or unpublished lab improvements are not numerical authority for this repository. Do not upload source PDFs, credentials, or private documents.

Before accepting a new numerical result, obtain an independent check of the source statement, field transfer, and arithmetic. Preserve the review scope and limitations. We welcome corrections to both values and provenance.
